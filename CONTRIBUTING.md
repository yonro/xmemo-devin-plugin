# Contributing

1. Keep the Devin adapter limited to manifest, skills, documentation, and validation.
2. Reuse XMemo server contracts; do not add a local memory backend or duplicate OAuth.
3. Run `python scripts/validate_package.py` and the test suite before opening a pull request.
4. Keep release and marketplace claims tied to actual commit, CI, Devin, and OAuth evidence.
5. Never commit credentials, personal memory data, or production configuration.
